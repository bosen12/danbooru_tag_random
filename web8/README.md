# web8：墨池工作台

墨池（web6）的新版面。規則、抽牌、生圖都跟墨池同一套，只換畫面和操作。

```
WEB_DIR=web8 WEB_BASE=web6 python server.py      # 預設埠照 config；.claude/launch.json 有 web8、web8-test
```

`WEB_BASE=web6`：web8 沒有的檔先到 web6 找，再退回共用的 web/（server.py 的 `static_path`）。
所以規則只有一份（web6 的 `mobile-bridge.js`、`gen.js`、引擎），卡冊、作品冊、疊印台、解析池也直接從 web8 點得到。
**web8 自己的檔一律 `w8-` 開頭**：跟 web6 同名的話，web6 的模組 import 到的會變成 web8 那支。

## 為什麼要重做

墨池走一遍看到的問題：

- **成品離按鈕太遠**：字盒、合成池、規則、按鈕、成品由上往下疊，按了生圖還要往下捲才看得到圖。
- **頂欄太擠**：連結、五個房間、分級、六顆圖示擠在上面，手機上第一屏有四成是頂欄。
- **規則和結果分開說**：一張圖用了哪些牌、哪張沒抽到、為什麼被拿掉，要點開「牌 · N」才看得到。

## 版面

一個畫面做完一輪：挑牌 → 生圖 → 看圖 → 改 → 再印。

```
┌ 頂欄：墨池 ｜ 全年齡 敏感 色情 ｜ ● Comfy ｜ 房間 ｜ ? ───────────────────────────┐
├ 字盒 ───────────┬ 舞台 ─────────────────────────────┬ 檢視 ───────────────┤
│ 搜尋               │ 配方：放進來的牌（份量、拿掉）    │ 規則｜這張          │
│ 花色               │ ┌──────── 畫布 ────────┐        │ 尺度、時代、人物、  │
│ 牌（往下捲一直有） │ │ 選中的那張：大圖、     │        │ 尺寸、每段張數、    │
│                    │ │ 印製中看著它顯影       │        │ 模型、LoRA          │
│                    │ └──────────────────────┘        │ ／這張用了哪些牌、  │
│                    │ 底片：這次印的每一張              │ 為什麼、提示詞      │
│                    │     [− 1 +] [抽牌] [生圖 ⌘↵]      │                     │
└────────────────────┴──────────────────────────────────┴─────────────────────┘
```

- 寬螢幕三欄；平板字盒收成抽屜；手機底下三個分頁（字盒、舞台、規則），生圖鈕一直在。
- 分級留在頂欄：它是全站共用的（卡冊、作品冊看的也是它），存在跟墨池同一個 `mochi.settings.v1`。
- 廢字簍也跟墨池共用（`mochi.bans.v1`）。配方存在這個分頁（sessionStorage），卡冊「送去墨池」的交接便條照收。

## 操作

| 鍵 | 做什麼 |
|----|--------|
| `/` | 找牌 |
| `Enter`（找牌框裡） | 放第一張 |
| 點牌 | 放進配方／拿出來 |
| 右鍵、`Alt`＋點牌 | 丟廢字簍／撿回來 |
| `D` | 只抽牌 |
| `Ctrl`＋`Enter` | 抽並生圖 |
| `←` `→` | 換底片上的上一張、下一張 |
| `Esc` | 關掉彈出來的東西 |

## 畫面

- 墨色底、紙白字、朱砂一個重點色（墨池的品牌色），份量和釘選用淡金。標題用 Chiron Sung（明體），其他用 Chiron Hei。
- 圖是主角：畫布上的圖盡量大，印製中看著預覽從模糊到清楚，印好用一圈墨暈開出來。
- 牌從字盒飛進配方；減少動態時全部改成直接出現。

## 檔案

| 檔 | 做什麼 |
|----|--------|
| `index.html` | 版面骨架 |
| `w8.css` | 全部樣式（含第一次準備面板借來的樣式） |
| `w8-main.js` | 開機、狀態、動作、快捷鍵、頂欄、生圖佇列 |
| `w8-state.js` | 存讀（跟墨池共用的鍵、自己的鍵、交接便條） |
| `w8-dom.js` | 建節點、提示條、彈出層 |
| `w8-library.js` | 字盒 |
| `w8-recipe.js` | 配方 |
| `w8-stage.js` | 畫布、底片、生圖鈕 |
| `w8-detail.js` | 這張用了哪些牌、提示詞、再印 |
| `w8-rules.js` | 規則 |
| `w8-models.js` | 底模、LoRA |

測試：`node scripts/test_web8_browser.mjs`（自己開伺服器、擋生圖）。
